fluidfield: site walk verification against BIM

An iOS capture app records ARKit poses, LiDAR depth, RoomPlan geometry, and the world map from a construction site walk. A pipeline registers each walk to the building model and to earlier walks (floor height match, FFT search over the floor plan, trimmed ICP). Every expected element gets a verdict of seen present, seen absent, or not seen, so the system abstains instead of guessing when its evidence is weak.

Egress Review Gym

An RL environment and a dataset of construction drawings with planted egress violations, built to train a small vision model to review code compliance. Early runs didn't learn; I'm working through why, and how violations should be planted.

Mozart Vision

The project's objective is the development of a Computer Vision system for the automatic interpretation of guitar sheet music, and converting it into guitar tablature. Uses Hough transform to detect and record the coordinates of the extreme points of horizontal staff lines, providing a reference for pitch placement. Subsequent morphological operations remove staff lines and rectify any resulting image irregularities. Further, image segmentation divides bars into individual notes, while corner detection pinpoints note locations. Centroid analysis links notes to nearby staff lines or spaces, enabling the determination of pitch, fret, and string positions. Lastly, a Convolutional Neural Network (CNN) classifies notes as whole, half, or quarter notes.

Rapidly Exploring Random Tree (RRT)

In this project, I ventured into the dynamic field of robotics path planning. The primary aim was to implement a Rapidly Exploring Random Tree (RRT) algorithm, a fundamental technique for optimizing routes in obstacle-laden maps. The project entailed the generation of random nodes and edges to methodically explore the configuration space. To enhance path quality, I incorporated the Dijkstra algorithm, ensuring efficient navigation from the starting point to the destination. This project granted me a valuable hands-on learning experience in robotics and path planning methodologies, allowing me to expand my skills in algorithm design and practical problem solving.
